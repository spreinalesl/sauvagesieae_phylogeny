# sauvagesieae_phylogeny

This directory contains all the scripts used to clean, select and assemble DNA reads from target-capture to reconstruct a phylogenetic hypothesis for Sauvagesieae (Ochnaceae).
We used two probe sets, the universal Angiospems353 and Ochnaceae specific probes in a dual-hybridisation reaction. Consequently scripts to detect and remove shared genes are included as well. Read mapping and assembly were performed using the hybpiper pipline, and phylogenetic inference was carried out following two approaches: a species tree approach using Weighted ASTRAL and Astral-Pro depending of the nature of data used to infer gene trees, and supermatrix approach in which all gene alignments were concatenated into a single matrix analysed using ML. All analyses were running in the Crop Diversity HPC (UK).
